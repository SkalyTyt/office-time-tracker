# Учёт времени в офисе

Сайт для отметки времени на рабочем месте. Без внешних зависимостей, нужен только Node.js 22+.

## Запуск
Windows: двойной щелчок по `start.bat`, либо `node server.js`. Сайт: http://localhost:3000

Первый вход: логин `admin`, пароль `admin123` — сайт сразу попросит задать новый пароль.

## Возможности
- Сотрудник: «Начал(а)» / «Закончил(а)», отдельный таймер вечернего времени, прикрепление заявлений, история отметок.
- Через 8 часов работы сайт спрашивает «Вы ещё работаете?» и при отрицательном ответе записывает указанное время окончания.
- Администратор: все отметки, вечернее время, заявления, журнал всех действий, управление сотрудниками и администраторами, просмотр логинов и паролей, выгрузка в CSV.
- Пароли меняет только администратор.

## Забыли пароль
На экране входа есть кнопка «Забыли пароль?» — заявка уходит администратору (она видна в его панели). Администратор задаёт новый пароль и сообщает его сотруднику лично.
Если забыл пароль единственный администратор: `node reset-password.js <логин> <новый пароль>` (на компьютере с сайтом).

## Демо-режим и выкладка на хостинг
При `DEMO_MODE=1` на чистой базе создаются демо-аккаунты: `admin / admin123` (администратор) и `test / test123` (сотрудник); их пароли менять нельзя.
Для боевой работы `DEMO_MODE` не задавайте; пароль администратора можно задать переменной `ADMIN_PASSWORD`.

Быстрая выкладка на Render (бесплатно, данные демо не сохраняются между перезапусками): файл `render.yaml` уже настроен —
https://render.com/deploy?repo=https://github.com/SkalyTyt/office-time-tracker

## Программа для рабочих компьютеров (Windows)
Папка `client/`. Сервер — компьютер администратора (включён всегда), на остальных ПК стоит программа:
- при включении ПК закрывает экран плашкой «Начать смену»; вход нужен один раз, дальше программа помнит сотрудника (хранится защищённый ключ, пароль не хранится);
- пока смена идёт, выключить или перезагрузить ПК нельзя — нужно нажать «Завершить смену»;
- если ПК выключился внезапно (свет), при следующем включении время между последним сигналом и возвратом не считается (пауза); если ПК не включали больше 4 часов, смена закрывается по последнему сигналу;
- администратор в разделе «Сотрудники» может нажать «Выйти с рабочего ПК» — на ПК сотрудника снова появится вход;
- нет связи с сервером — можно работать без связи, время сохранится на ПК и отправится позже.

Установка: `client\build.bat` (собирает `OfficeTimeClient.exe` встроенным компилятором Windows), затем на каждом ПК запустить `client\install.bat` (адрес сервера, например `http://192.168.1.10:3000`). Для проверки без блокировок: `OfficeTimeClient.exe --windowed`.
На компьютере администратора откройте порт: `netsh advfirewall firewall add rule name="OfficeTime" dir=in action=allow protocol=TCP localport=3000` (от администратора), и настройте автозапуск `node server.js` при входе в Windows.
Ограничения: плашку и запрет выключения может обойти сотрудник с правами администратора на ПК (диспетчер задач, принудительное выключение). Для защиты работайте под обычной учётной записью и отключите диспетчер задач политикой Windows.

## Данные
Папка `data/` (база, загруженные файлы, ключ шифрования `secret.key`) создаётся автоматически и в репозиторий не попадает. Копируйте её целиком для резервной копии.
