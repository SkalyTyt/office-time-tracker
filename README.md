# Учёт времени в офисе

Сайт для отметки времени на рабочем месте. Без внешних зависимостей, нужен только Node.js 22+.

## Запуск
Windows: двойной щелчок по `start.bat`, либо `node server.js`. Сайт: http://localhost:3000

Первый вход: логин `admin`, пароль `admin123` — сайт сразу попросит задать новый пароль.

## Возможности
- Сотрудник: «Начал(а)» / «Закончил(а)», отдельный таймер вечернего времени, прикрепление заявлений, история отметок.
- Через 8 часов работы сайт спрашивает «Вы ещё работаете?» и при отрицательном ответе записывает указанное время окончания.
- Администратор: все отметки, вечернее время, заявления, журнал всех действий, управление сотрудниками и администраторами, просмотр логинов и паролей, выгрузка в CSV.
- Пароли меняет только администратор.

## Данные
Папка `data/` (база, загруженные файлы, ключ шифрования `secret.key`) создаётся автоматически и в репозиторий не попадает. Копируйте её целиком для резервной копии.
